# Домашнее меню — Telegram-бот (Home Assistant add-on)

Жена открывает бота, выбирает кухню и блюдо. Ей приходит приятное сообщение,
а тебе — название блюда и список ингредиентов. Работает через long polling,
внешний домен и открытые порты не нужны.

## Что внутри

```
menu-bot-addon/            ← это и есть репозиторий для Home Assistant
├── repository.yaml        ← описание репозитория add-on'ов
├── export_menu.py         ← экспорт рецептов из Excel в menu.json (запускать на ПК)
├── README.md
└── menu_bot/              ← сам add-on
    ├── config.yaml        ← манифест add-on (настройки)
    ├── build.yaml         ← базовые образы (ghcr.io, не Docker Hub)
    ├── Dockerfile
    ├── requirements.txt
    ├── bot.py             ← код бота
    ├── menu.json          ← данные меню (41 блюдо, уже сгенерированы)
    └── config.sample.json ← пример конфига для локального теста
```

## Шаг 1. Создать бота и получить токен

1. В Telegram открой **@BotFather** → `/newbot` → задай имя и username.
2. Скопируй **токен** вида `123456:AA...`. Его вставишь в настройки add-on (шаг 4).

## Шаг 2. Узнать Telegram ID (свой и жены)

1. Открой **@userinfobot** и нажми Start — он покажет твой числовой ID.
2. Попроси жену сделать то же самое и прислать её ID.
3. Твой ID пойдёт в `owner_id` (тебе приходят заказы). Оба ID — в `allowed_ids`.

## Важно про сборку (Docker Hub заблокирован)

Home Assistant при обычной установке **собирает образ на самом сервере**, а для этого
тянет вспомогательный образ `docker:*-cli` с Docker Hub — в РФ он блокируется
(в логе: `Can't pull image docker:...-cli: 403 denied`). Поэтому мы **не собираем на устройстве**,
а собираем образ в **GitHub Actions** и кладём в **GHCR (ghcr.io)** — оттуда HA просто скачивает
готовый образ (ghcr.io доступен). Это уже настроено в `.github/workflows/build.yml`.

## Шаг 3. Подготовить репозиторий

1. Впиши свой GitHub-логин (строчными буквами) в двух местах:
   - `menu_bot/config.yaml` → строка `image: "ghcr.io/ВАШ_GITHUB_LOWERCASE/menu-bot-{arch}"`;
   - `repository.yaml` → `url` на адрес своего репозитория.
2. Залей папку `menu-bot-addon` в **новый GitHub-репозиторий** (ветка `main`).

## Шаг 4. Собрать образ в GitHub Actions

1. После пуша открой на GitHub вкладку **Actions** — workflow «Build and publish add-on»
   запустится сам (или запусти вручную кнопкой **Run workflow**). Он соберёт образы
   для aarch64 и amd64 и запушит их в GHCR.
2. Когда сборка станет зелёной, открой профиль GitHub → **Packages** → пакет `menu-bot-aarch64`
   → **Package settings** → **Change visibility** → **Public**. (Так HA скачает образ без логина.)

## Шаг 5. Установить в Home Assistant

1. **Настройки → Дополнения → Магазин дополнений**.
2. Справа вверху **⋮ → Репозитории**, вставь URL своего GitHub-репозитория, **Добавить**.
3. В списке появится **«Домашнее меню — бот»** → открой → **Установить**
   (HA скачает готовый образ с ghcr.io — локальная сборка и Docker Hub не задействуются).
4. Вкладка **Конфигурация** — заполни:
   - `bot_token` — токен от BotFather;
   - `owner_id` — твой ID;
   - `allowed_ids` — список ID (твой и жены), по одному в строке;
   - `menu_url` — оставь пустым (или см. «Обновление меню»).
5. **Сохрани**, вернись на вкладку **Информация**, включи **«Запускать при загрузке»**
   и **«Watchdog»**, нажми **Запустить**. В **Журнале** должно быть «Бот запущен».

Готово — жена жмёт Start у бота и пользуется.

> При обновлении бота: подними `version` в `menu_bot/config.yaml`, запушь — Actions пересоберёт
> образ с новым тегом, а в HA появится кнопка «Обновить».

## Обновление меню (когда правишь рецепты)

Вариант А — пересобрать данные:
1. На ПК: `pip install openpyxl`, затем в папке `C:\Menu` запусти
   `python menu-bot-addon\export_menu.py "C:\Menu" "C:\Menu\menu-bot-addon\menu_bot\menu.json"`.
2. Закоммить обновлённый `menu.json` в репозиторий.
3. В HA у add-on нажми **Пересобрать/Обновить**.

Вариант Б — без пересборки (удобнее):
1. Положи `menu.json` в репозиторий и возьми «raw»-ссылку GitHub
   (`https://raw.githubusercontent.com/.../menu.json`).
2. Впиши её в настройку `menu_url`. Бот будет брать меню по ссылке при старте —
   тогда достаточно обновить файл в репозитории и перезапустить add-on.

## Локальный тест (по желанию, на ПК)

```
cd menu_bot
pip install -r requirements.txt
copy config.sample.json config.json   # впиши bot_token и owner_id
python bot.py
```

## Примечания

- Токен и ID хранятся в настройках add-on внутри твоего Home Assistant — в коде их нет.
- Если `allowed_ids` пуст и `owner_id` = 0 — бот открыт для всех. Для приватного режима
  оставь заполненными `owner_id` и `allowed_ids`.
- Бот только читает меню и шлёт сообщения — ничего не покупает и не платит.
